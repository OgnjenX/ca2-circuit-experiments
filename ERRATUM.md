# Recorded backend correction

state defect. See the [experiment 002 erratum](experiments/002_sun2021_ca2_frequency/ERRATUM.md).
Historical artifacts and integrity checks are preserved. The corrected revision of experiment 002 (formerly numbered 003)
uses a new backend identity, a frozen independent oracle and prospective STP,
static-release and linear-summation controls.
