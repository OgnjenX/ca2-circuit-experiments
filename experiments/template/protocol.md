# Protocol

## Question and expected observation

Specify the biological target and its original measurement conditions.

## Sources and model

Record dataset identifiers, permissions, preprocessing, model commit and simulator
version. List measured, fitted, default and missing parameters.

## Calibration and validation

Separate observations used for fitting from the held-out checks. Set quantitative
acceptance criteria before examining validation outcomes.

## Inputs, outputs and controls

Specify trial timing, state reset, sampling, interventions and paired seeds.

## Analysis and numerics

Declare the primary measure, train/test split, uncertainty, numerical tolerances
and handling of failures. Keep secondary analyses labeled as secondary.

## Run record

Record the frozen commit, input hashes, configuration, environment and outputs.

## Interpretation limits

State what agreement would support, what failure would imply and what the
experiment cannot establish.
