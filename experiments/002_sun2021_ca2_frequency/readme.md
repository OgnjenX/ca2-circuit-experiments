# Experiment 002: CA2 frequency-response assay

This is the canonical corrected revision of experiment 002. It was originally
recorded as `003_corrected_ca2_frequency`; that provisional number is retired.
The next independent scientific question can use experiment 003.

[The report](report.md) contains the unchanged corrected outcomes: 240 STP/static
runs, 60 numerical comparisons, and no passing setup. The independent synaptic
oracle passes; the neuronal train assay remains numerically sensitive and does
not establish biological validity. Hippocampome remains useful for specifying
hypotheses whose simulator and biological assumptions require testing.

Scientific inputs, scores, evidence manifests and raw archive identities retain
their frozen bytes and recorded identifiers, including references to experiment
003 inside those records. These references identify the corrected revision of
002; they do not describe a separate active study. See the exact commit/path map
in [provenance_map.json](provenance_map.json), the [erratum](ERRATUM.md), and
[reproduction instructions](reproduce.md).

The defective original revision is preserved in Git history and the
`experiment-002-v1` release. The corrected revision's existing release remains
