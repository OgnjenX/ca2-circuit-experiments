# Experiment 001: CA2 input-pattern transmission

**Status:** completed exploratory model study. Biological adequacy remains limited.

Question: does modeled CA2 pyramidal output contribute information that lets a
downstream CA1 sample distinguish two rate-matched cortical input patterns?
Does prescribed CA3 input change that contribution?

- [Protocol](protocol.md): task, controls and analysis rules.
- [Results](results.md): findings and limits.
- [Report](report/ca2_scientific_experiment.pdf): figures, methods and interpretation.
- [Methods](methods.md): detailed original methods.
- [Frozen plan](reference/frozen-task-protocol.json): exact nominal configuration.
- [Source map](provenance/source_map.json): original paths and repository copies.
- [Reproduction](../../docs/reproduction.md): inspection, archives and fresh runs.

`implementation/` contains unchanged historical scripts. `reference/` contains
the completed study's JSON evidence, not the output of a new run. The original
raw data and binaries are release assets listed in `../../artifacts/experiment_001.json`.

The study completed 288 core runs and 1,584 matched readouts covered by the
nominal and extended audits. Additional calibration and excluded attempts are
retained in the recorded archive. A source-code cleanup cannot retroactively
change the frozen protocol or turn these results into behavioral validation.
