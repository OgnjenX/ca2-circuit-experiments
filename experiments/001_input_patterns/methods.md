CA2-centered CARLsim experiment: methods and interpretation boundaries

The question is whether the modeled CA2 pyramidal output contributes distinguishable cortical input-pattern information to a downstream CA1 target sample, with and without competing CA3 input. This is an information-transmission experiment. It does not implement social familiarity, learning, consolidation, or behavior.

The nominal core contains all five exported CA2 types: 18,956 pyramidal, 105 basket, 147 wide-arbor basket, 79 bistratified, and 94 SP-SR cells. Prescribed input pools contain 10,818 MEC layer-II stellate and 4,096 CA3 afferents. The CA3 pool is an assay cohort, not the full exported anatomical CA3 population. Unrepresented inputs are assumed silent. Connections are random with exported probabilities; the model has no explicit dendrites, laminar integration, or spatial arrangement.

The CA1 assay contains 128 pyramidal targets and exported counts of 819 basket and 1,962 bistratified cells. It retains the implemented CA2, direct CA3, and inhibitory connections into these populations. It omits CA1 pyramidal feedback and feedback to upstream regions. It does not specifically represent ventral CA1. The export also contains a connection to an unrepresented CA1 CCK basket population; that row is not silently mapped to the represented basket population.

Exported Izhikevich and pair-specific short-term synaptic-plasticity parameters are retained. These are fitted effective point-neuron parameters, not necessarily direct measurements of each biological quantity. Intrinsic standard deviations are zero. AMPA and GABAa conductances are active; NMDA and GABAb multipliers remain zero as in the packaged driver. No long-term learning rule is enabled. A SYN_PLASTIC connection label is not evidence of simulated learning.

Physiological calibration uses Chevaleyre & Siegelbaum (2010), https://pmc.ncbi.nlm.nih.gov/articles/PMC2905041/ . Single-pulse excitatory targets with inhibition blocked are 7.4 +/- 0.9 mV for aggregate entorhinal layer-II input (n=8) and 10.8 +/- 2.2 mV for CA3 Schaffer collateral input (n=7). Reported errors are SEM. The stimulated afferent counts selected against these targets are 9,800 MEC cells and 1,940 CA3 cells. Electrical stimulation voltage has no direct simulator equivalent; these counts are fitted model conditions, not measured fiber recruitment. MEC layer II is a subset of the paper's aggregate entorhinal layer-II pathway.

The unchanged model does not reproduce the strong published CA3-evoked inhibitory response. After matching excitation, the mean intact-minus-inhibition-removed voltage difference across its 128 monitored pyramidal cells has a minimum of about -0.27 mV, compared with the published inhibitory response of -13.8 +/- 2.4 mV (n=7). These monitored-subset model traces are not animal replicates and are not an exact slice reconstruction.

The experiment-specific revised simulator uses an assumed GABAa reversal of -77.8 mV throughout CA2 and CA1. This estimate is based on nominal chloride concentrations and temperature in the recording recipe, not a measurement of CA2 GABAa reversal. Bicarbonate permeability, ionic activity and junction potentials can change the effective reversal. The original simulator and original -70 mV library are preserved. CPU and GPU implementations use the same experiment-specific compile-time reversal constant.

Only the four inhibitory-to-CA2-pyramidal connection weights receive a fitted aggregate multiplier of 100. Other weights, including inhibitory-to-interneuron weights, retain exported values. This is a large phenomenological correction, not a measured conductance or an unchanged Hippocampome model. The resulting single-pulse inhibitory difference is about -13.65 mV. Calibration is not independent validation. The global inhibitory-gain attempt is retained as an excluded model revision because it failed numerical convergence checks.

Unused five-pulse 100 Hz trains provide qualitative physiological checks. The published CA3 train elicits spikes in 0/8 CA2 cells with inhibition intact and in 6/8 after global drug blockade. The model's target-only removal of inhibition is not an exact PTX/CGP drug simulation, and initial voltages also differ from the recorded drug condition. The revised model shows strong relative suppression; a small residual model response is reported, not hidden or forced to zero. Quantitative layer-III entorhinal spike/inhibition targets are not applied to the modeled MEC layer-II pathway.

Numerical checks compare RK4 20 versus 40 substeps/ms for physiological trains and actual task inputs at the excluded calibration network seed 20. Every CA2 population must have spike-count differences <=5% (a difference <=1 is tolerated only when both counts <=1), and first pyramidal spike latency must agree within 1 ms. Complete finite voltage, adaptation and current records are checked for monitored cells of every CA2 type. CA1 readout checks at 40 versus 80 substeps/ms use the same count and latency criteria plus <=0.5 mV RMS difference of the baseline-subtracted window-mean voltage features. The earlier 20 versus 40 readout check fails one small basket count comparison and remains recorded. The frozen nominal experiment uses 40 substeps/ms.

The controlled task uses two equally large cortical patterns sharing 8,820 of their 9,800 active cells. Each source cell receives five events at 100 Hz with independent 0-2 ms jitter. Optional CA3 input uses 1,940 fixed cells and a train starting 25 ms after cortical input. Synthetic identity labels identify the input pattern only. Every trial starts a new simulator process; membrane, adaptation and synaptic states reset. This avoids the strong trial-history carryover observed in the excluded original 300 ms-spaced pilot.

Five independently generated networks use seeds 31-35, excluding calibration seed 20. Each network has 16 trials: two patterns, two CA3 contexts and four repetitions. Within each context/pattern, the first two repetitions are training and the last two are testing. Connectivity is held fixed within a network seed; input jitter varies by the predetermined stimulus generation seeds. All event files and the nominal executable are hashed before execution.

Each CA2 trial supplies three matched CA1 replays: intact pyramidal output; deleted pyramidal output; and a trial-specific bijective permutation of pyramidal cell identities. The scrambled control preserves every spike time, population count and individual cell train up to ID remapping. The four CA2 inhibitory streams and direct CA3 input remain identical in all three controls. This intervention concerns pyramidal output, not silencing all CA2 cells. Recorded delivery of all prescribed/replayed input streams is verified against the exact event files.

The primary readout is CA1 identity decoding from 128 cells' counts in four 50 ms response windows. A nearest-class-centroid Euclidean classifier is trained only on designated training trials, separately for each network, context and output condition. Equal distances receive 0.5 accuracy. No classifier tuning or selection of a better-performing method is permitted. A rate-only decoder is reported separately. A prespecified secondary decoder uses each target's mean membrane voltage in the same windows, subtracting its 40-49 ms baseline. Secondary voltage information is not called spike transmission or memory, and cannot replace a null primary result.

Input-positive controls exercise the frozen feature/classifier functions. Cell-pattern input features must give 100% held-out identity accuracy; aggregate input-count features must give 50% because counts are exactly equal. These validate stimulus labels and analysis implementation, not biological fidelity.

The five network seeds are model replicates, not animals. Paired intervention effects are computed per seed. Descriptive uncertainty uses the exact five-seed bootstrap distribution. A balanced label-permutation null is calculated within network, context and split. Results must include per-seed values, all null/negative results and limited power; neurons and time bins are not independent experimental replicates.

Sensitivity analyses vary the assumed GABAa reversal (-75/-80 mV), fitted inhibition (50/150), and effective outgoing CA2 coupling (half/double on three represented exported rows flagged as defaults). These ranges are exploratory perturbations, not measured confidence intervals. Core sensitivity uses the first preselected independent seed, 31; output-coupling sensitivity uses all five nominal networks. Coverage and any numerical failures must be stated. A convenient sensitivity variant is not selected to replace the nominal frozen result.

CARLsim console summaries use an integer-second denominator and show NaN rates for subsecond trials. Scientific measurements come from complete binary spike and voltage monitors, not those console summaries.

Reproducibility: frozen-task-protocol.json records the executable, sources, input files and analysis hashes. run_reset_task.py runs or safely resumes only fully verified completed trials; it refuses to overwrite an unfinished existing run. Python uses the bundled runtime with NumPy. The simulator uses CUDA 12.4, sm_86 code generation, g++-12 and the existing CARLsim branch with pair-specific STP. NVIDIA access is required; sandboxed environments without GPU devices cannot execute these jobs. For an independent rerun, copy this experiment directory beside the existing ca2-simulation directory while excluding runs, replays and execution-completion files, retain the frozen executable/protocol/stimuli, and run the copied run_reset_task.py with the same runtime and NVIDIA access. Do not overwrite the current experiment's run directories.

Scientific conclusions must remain conditional on the revised fitted model, mixed parameter provenance, open-loop inputs, sampled readout and omitted circuitry. A result can establish what this modeled circuit transmits under these conditions and identify where its assumptions fail. It does not establish CA2 function in an animal or demonstrate social recognition memory.

Additional CA1 adequacy check: the same 1,940-afferent single Schaffer collateral pulse calibrated against CA2 drives all 128 CA1 targets to spike, both with intact target inhibition and after removal of the four inhibitory-to-CA1-pyramidal pathways. The reference 17.5 +/- 2.6 mV subthreshold EPSP (n=8, Figure 3) cannot be compared with spike peaks. Model baseline (-69.36 mV) differs from the reference holding voltage (-73 mV), so this is not a matched slice replication or independent proof of an excitatory-amplitude mismatch. Downstream biological validity remains unestablished; strong direct CA3 drive can mask smaller CA2 effects. Details: ca1-adequacy-plan.json and ca1-adequacy-results.json. The nominal model was not changed.

Unseen-input generalization: prepare_generalization.py creates 24 new trials for seed 31. extend_generalization.py prospectively extends these exact inputs across seeds 32-35, giving 120 core trials and 360 matched replays. The extension was defined before inspecting nominal decoder outcomes, and the original plan is retained. Patterns replace 10% or 50% of the 980 distinctive cells, corresponding to 1% or 5% of all 9,800 active cells. Total activity stays fixed. Labels follow the majority of the original identity-specific pool. The larger replacement deliberately leaves only a small 38-cell class margin. Other trials use CA3 delays of 15 or 35 ms instead of 25 ms. All new inputs are tests: centroids remain fixed to the original nominal training trials separately per network, context and intervention. No retraining occurs. These are variants of synthetic classes, not novel animal identities or memory tests. Generalization-input-audit.json verifies every input hash, active count, timing range and fixed input positive control. The total-count control remains at chance. Five-seed paired bootstrap intervals describe model network variability, not animals.

Secondary response descriptions: analyze_response_dynamics.py records response rates, population and responsive-cell latencies, responsive fractions, within-class repeat cosine similarity, between-class cosine similarity and class-centroid distance. Silent vectors have undefined cosine; silent cells are omitted from latency summaries and their fraction is reported. These descriptive measures use all repeats and do not change the frozen classifier or select a primary outcome. Response rates refer to the 200 ms stimulus response, not sustained in-vivo firing. Analyze_context_responses.py compares core response rates across nominal and parameter variants. Cortical jitter is separately drawn in each context, so this is a descriptive context comparison rather than an exact matched-input counterfactual for adding CA3.

Parameter interpretation: reversal variants change the global GABAa reversal in both CA2 and CA1. The fitted inhibitory-gain variants change only the four inhibitory-to-CA2-pyramidal connections. Output-gain variants change three represented default-flagged CA2-pyramidal output connections. A reversal sensitivity effect is not isolated to CA2 inhibition. Core variants and full-core numerical sensitivity use preselected network 31; other coupling and readout precision checks use all five networks.

Numerical sensitivity of inferred effects: all nominal replays are repeated at 80 substeps/ms using the original 40-substep core streams, and all 16 seed-31 core trials and their replays are repeated at 80 substeps. Frozen classifiers and splits are reused for effect comparisons. Additionally, run_variant_precision.py repeats identity-0, repeat-0 trials in both contexts for each of four core parameter variants, at 80 substeps. This gives eight core runs and 24 replays. The existing count, latency and voltage criteria are retained; every failure is reported. These spot checks do not establish full classifier convergence in every variant. Core-variant-precision-plan.json records this extension before inspecting variant outcomes.

Independent audit: nominal-experiment-audit.json verifies all nominal trial inputs, replay transformations, finite complete monitored records, reset baselines and aggregate connection-count signatures. Extended-experiment-audit.json covers every sensitivity and generalization run, including precision spot checks. Aggregate connection counts are not individual-edge hashes; matching seeds and event-loader code support topology matching. Voltages are recorded for the monitored subsets (at most 128 cells per group), while spikes are recorded for every modeled cell.

Backend provenance: CARLsim4 branch feat/meansdSTPPost_hc, source commit11ea96f750d125e4dcfbf67231429204322fa1bd, with documented GPU architecture, monitor-capacity and inhibitory-reversal changes. This is the archived local implementation, not an assumed equivalent simulator release.

Fresh reproduction-copy validation: REPRODUCE.txt and prepare_reproduction_copy.py provide the full sequential workflow, retaining two exact historical unit-gain reference folders separately from new results. An actual isolated copy verified all14frozenartifacthashes,160nominalinputfiles,120newinputtrials, CUDA shared-library resolution and bundled NumPy/ReportLab/Pillow dependencies. No fresh task outputs or completion markers were copied. This verifies the copy/prerequisites, not a second full GPU rerun; details are in reproduction-copy-validation.json.

New-input core response descriptions use the same nominal response window and count/latency definitions. Generalization-results.json retains all five CA2 populations' response counts, rates, responsive fractions and latencies for every unseen-input trial. These descriptive summaries do not select a decoder or replace the primary test. Timing comparisons with nominal inputs include fresh jitter, so they are not exact matched-jitter counterfactuals.

Readout training scope: the feature definitions, nearest-centroid algorithm and trial split are fixed. Nominal and sensitivity analyses fit centroids separately on each network/context/condition/variant's designated training responses. This tests available pattern information after the external readout is trained for that condition; it is not transfer of one unchanged learned readout through an acute lesion or parameter change. Generalization is different: its centroids use only the corresponding original nominal training responses, with no retraining on any new input. This clarification changes wording, not features, scores, splits or inference rules.

Backend source audit: the preserved upstream source archive SHA-256 matches its recorded hash, and the archive comment directly identifies commit 11ea96f750d125e4dcfbf67231429204322fa1bd. Backend-source-provenance.json hashes 77 source/build files for each of the three locally patched libraries and records their library hashes and build logs. The archived builds retain 16 compiler warning lines per library, including CPU thread-wrapper return-type warnings. Circuit constructors use GPU_MODE, and an inspected nominal runtime explicitly reports one GPU and zero CPU partitions. CPU simulation is not validated by this experiment. Source patches include CUDA12 texture-access compatibility, checked CUDA calls/timer helpers, monitor-buffer reduction, architecture targets and the reversal constant. Exact archived commands include O3 and host -ffast-math. The warnings are retained, not silently repaired during a frozen run. Numerical and biological validation remain separate from this provenance audit.
